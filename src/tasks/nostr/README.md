Family 9: Nostr coordination under a protected key, and the bitchat Bluetooth mesh. Specified in docs/tasks.md section 10: protecting the key (custody, custody_hot), posting where the audience reads (publish), delivering private messages (private), buying a service from a counterparty (counterparty), and delivering when the internet is down (mesh_outage, mesh_partial). The cells are not implemented. The protocol core is: BIP-340 (secp256k1.ts), NIP-19 (bech32.ts), NIP-01 (event.ts), NIP-44 v2 (nip44.ts), and NIP-59 with NIP-17 (nip59.ts), tested in nostr.test.ts against the published vectors in data/nostr/.
